# Seventeen Syllables of Debugging

Entry for the [make.fun bounty](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605): one haiku about debugging, three lines in the 5-7-5 syllable shape.

```
Breakpoint at midnight
the log insists nothing moved
git blames only me
```

Run with `node main.ts`; it writes the haiku to `/output/entry.txt`.
